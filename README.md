# skygate

[![ci](https://github.com/day0ops/skygate/actions/workflows/ci.yml/badge.svg)](https://github.com/day0ops/skygate/actions/workflows/ci.yml)
[![release](https://img.shields.io/github/v/release/day0ops/skygate)](https://github.com/day0ops/skygate/releases)
[![go version](https://img.shields.io/github/go-mod/go-version/day0ops/skygate)](go.mod)
[![license](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

skygate is a living flight-ops demo: a simulated airline operation with a live "mission control" dashboard, built to make API gateway demos feel real.

In the future, more features will be added as we develop this simulator further.

## Quickstart

```bash
make run
```

Then open http://localhost:8080.
